# Temporally-Constrained-Local-Reconstruction-Embedding-TCLRE
The Temporally Constrained Local Reconstruction Embedding (TCLRE) is a method for dimensionality reduction of sequential, nonlinear sensor data. It is particularly suited to Wind Turbine Generator (WTG) SCADA data, where measurements such as generator temperature, bearing temperature, vibration, and power output evolve over time.
